# 크기·색·간격 같은 시각 판단 값은 그릴링 때 확신이 없으면 fg-visual을 먼저 제안한다

이 프로젝트에서 폰트 크기·색 톤·여백처럼 "눈으로 봐야 정해지는 값"을 텍스트 그릴링만으로 합의하면, 실행 후 화면을 보고서야 뒤집히는 일이 다섯 번 반복됐다(검색 패널 → 전체메뉴 → nav 폰트 크기 → Cards 카드 그리드 → 이번 제목 스케일 통일). 매번 "합의했다고 생각한 값"이 실제 화면에서는 다르게 느껴져 여러 라운드의 재작업이 들어갔다. 대안(그냥 텍스트로 계속 왕복 vs 매번 fg-visual 사용)을 검토한 결과, 앞으로 이런 종류의 값을 그릴링할 때는 "말로 설명하면 충분한가"를 먼저 판단하지 말고, 시각적 판단이 조금이라도 개입되면 기본값을 fg-visual 제안으로 둔다. 되돌리기 쉬운 결정이지만, 이 프로젝트에서만 다섯 번 반복된 패턴이라 그릴링 습관 자체를 바꿔야 한다는 근거로 명문화한다.
