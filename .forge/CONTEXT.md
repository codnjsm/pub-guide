# Pub-Guide

현대자동차 홈페이지(hyundai.com/kr/ko/e)의 UI 패턴을 참고해 Vue 3 + Vuetify로 재현한 컴포넌트 스타일가이드 프로젝트.

## Language

**스타일가이드 (Style Guide)**:
현대차 페이지의 UI 패턴(헤더, 히어로 배너 등)을 Vuetify 컴포넌트로 재현해, 미리보기와 코드를 나란히 볼 수 있게 만든 컴포넌트 카탈로그.
_Avoid_: 퍼블리싱 가이드, 마크업 가이드 (설명 위주의 문서형 가이드로 오인될 수 있음 — 이 프로젝트는 코드/프리뷰 중심의 카탈로그다)

**섹션 페이지 (Section View)**:
`src/views/*.vue` 중 하나. 현대차 페이지의 UI 패턴 하나(헤더, 슬라이드 네비게이션, 히어로 배너 등) 또는 여러 패턴에 걸쳐 반복되는 컴포넌트 하나(버튼 등)에 대응하는 최소 단위.

**CodePreview**:
`src/components/guide/CodePreview.vue`. 미리보기/코드 탭 전환과 코드 복사 버튼을 제공하는 공용 프레젠테이션 컴포넌트. 모든 섹션 페이지가 이 컴포넌트로 예시를 감싼다. 한 섹션 페이지가 이 컴포넌트를 여러 번 쓸 수도 있다(카테고리별로 독립된 미리보기/코드가 필요할 때, 예: Buttons).
